# 主题与安装包分发设计

## Context

现有顶栏左侧的三个入口依次为新建连接、新建命令和 WebDAV 配置，设置位于右侧。桌面应用使用 Tauri 2。Windows x64 分发 NSIS 安装包，macOS Intel 和 Apple Silicon 分发 DMG。

## Decisions

### 主题启动与切换

在 main.ts 挂载启动页前读取独立的本机偏好键。保存值为 `system`、`light`、`dark`。跟随模式监听系统外观变化，固定模式保持用户选择。存储及媒体查询不可用时按主题规格降级。

全局和工作台样式共享语义颜色。xterm 在原实例上更新调色板，保留输入、选区和滚动历史。设置对话框关闭后归还键盘焦点。

### 手动升级

应用内升级器、更新接口和安装门闩已撤回。用户通过 GitHub Releases 获取对应平台的安装包，在结束当前工作并退出应用后手动安装。

正式标签触发版本一致性检查和三平台构建。所有目标通过后，发布作业收集安装包及 SHA-256 校验文件，生成 GitHub Release 草稿。维护者验收后可发布草稿。Windows 使用未签名的 NSIS 安装包，macOS 使用临时签名的 DMG。平台提示可能因系统策略而异。
