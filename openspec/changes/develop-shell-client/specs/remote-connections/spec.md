# Spec Delta

## Purpose

定义用户管理和建立 SSH 远程连接时可依赖的资料模型、认证方式、主机身份校验、测试反馈与生产环境标识，为终端和监控能力提供统一连接入口。

## ADDED Requirements

### Requirement: 管理 SSH 连接资料
系统 SHALL 允许用户创建、查看、编辑、复制、分组和删除 SSH 连接；连接至少包含名称、主机、端口、用户名、认证方式、备注和生产环境标识。

#### Scenario: 创建最小连接
- **GIVEN** 用户提供唯一名称、主机和用户名
- **WHEN** 用户保存连接
- **THEN** 系统使用默认 SSH 端口 22 创建连接并在连接列表中显示

#### Scenario: 删除存在活动会话的连接
- **GIVEN** 连接仍有关联的活动终端会话
- **WHEN** 用户请求删除连接
- **THEN** 系统提示受影响会话并要求用户明确确认
- **AND** 用户取消时连接和会话均保持不变

### Requirement: 支持常用 SSH 认证方式
系统 SHALL 支持密码、私钥及 SSH Agent 认证；保存秘密时 MUST 使用平台安全凭据存储，未选择保存的秘密仅在当前连接尝试期间驻留内存。

#### Scenario: 使用受口令保护的私钥连接
- **GIVEN** 用户选择有效私钥并提供正确口令
- **WHEN** 用户建立连接
- **THEN** 系统完成密钥认证且不会将私钥口令写入普通配置或日志

#### Scenario: 临时密码认证
- **GIVEN** 用户未选择保存密码
- **WHEN** 当前连接尝试结束或应用退出
- **THEN** 系统清除该密码且后续连接要求重新输入

#### Scenario: 安全保存私钥
- **GIVEN** 用户选择保存私钥及其可选口令
- **WHEN** 系统保存该连接的认证材料
- **THEN** 私钥和口令存入操作系统安全凭据存储，普通连接配置只保存引用
- **AND** 后续界面只显示是否已保存，不回显私钥或口令
- **AND** 连接目标变化时不得将已保存私钥静默用于新目标

#### Scenario: 删除已保存的私钥
- **GIVEN** 连接存在已保存的私钥
- **WHEN** 用户选择删除已保存私钥
- **THEN** 系统通过可恢复的凭据清理流程删除该秘密
- **AND** 删除结果未知时系统提示用户核查状态，不声称已成功或失败

### Requirement: 校验远程主机身份
系统 MUST 在首次连接时展示主机密钥指纹并取得用户信任，在已信任主机的密钥发生变化时阻止自动连接。

#### Scenario: 首次连接未知主机
- **GIVEN** 本地不存在目标主机的受信任指纹
- **WHEN** SSH 握手返回主机密钥
- **THEN** 系统展示主机、端口、算法和指纹并等待用户接受或拒绝

#### Scenario: 已知主机密钥变化
- **GIVEN** 目标主机返回的指纹与已保存指纹不一致
- **WHEN** 用户尝试连接
- **THEN** 系统中止连接并显示主机身份可能变化的高风险警告
- **AND** 系统不得静默替换已保存指纹

### Requirement: 测试连接并返回分阶段结果
系统 SHALL 提供可取消且有超时的连接测试，区分网络解析、TCP 建连、SSH 握手、主机校验和认证阶段，并返回稳定错误码。

#### Scenario: 连接测试成功
- **WHEN** 用户对有效配置执行连接测试
- **THEN** 系统报告已完成 SSH 握手和认证，并显示非敏感的服务器标识

#### Scenario: 用户取消连接测试
- **GIVEN** 连接测试尚未完成
- **WHEN** 用户取消测试
- **THEN** 系统停止进行中的网络操作并释放临时凭据和连接资源

### Requirement: 持久化生产环境标识
系统 SHALL 允许用户将连接标识或取消标识为生产环境，并在连接列表、会话标签和危险命令确认界面中持续展示该状态。

#### Scenario: 标记生产连接
- **WHEN** 用户将连接标识为生产环境并保存
- **THEN** 系统在所有使用该连接的界面展示醒目且一致的生产标识
- **AND** 后续命令提交使用保存后的生产状态执行安全判定

### Requirement: 跨入口共享连接行为
系统 SHALL 通过统一业务契约为 Tauri 与 HTTP 入口提供等价的连接列表、保存、测试和删除行为；入口不得各自实现连接规则。

#### Scenario: 通过不同入口读取连接
- **GIVEN** 同一数据目录中已有连接资料
- **WHEN** Tauri 客户端或 Web 客户端请求连接列表
- **THEN** 两种入口返回相同的非敏感连接字段和生产环境标识
- **AND** 响应均不包含可直接使用的秘密值

### Requirement: 在连接工作台中提供连接管理侧栏

系统 SHALL 在连接工作台左侧提供连接管理侧栏，展示分组、连接名称、连接状态、生产环境标识和搜索/筛选入口，并提供“新建连接”功能菜单。侧栏 SHALL 支持收起、展开和调整宽度，不能因面板变化丢失当前连接选择。

#### Scenario: 从顶部菜单新建连接

- **GIVEN** 用户位于连接工作台
- **WHEN** 用户选择“新建连接”
- **THEN** 系统打开连接编辑流程并在保存后将新连接加入左侧连接管理
- **AND** 连接保存失败时不创建半成品列表项

#### Scenario: 调整连接侧栏不改变会话

- **GIVEN** 当前连接存在活动终端或文件面板
- **WHEN** 用户收起、展开或拖动左侧连接管理侧栏
- **THEN** 当前连接、终端输出和文件浏览状态保持不变
