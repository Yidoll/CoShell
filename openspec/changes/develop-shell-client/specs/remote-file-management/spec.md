# Spec Delta

## ADDED Requirements

### Requirement: 通过 SFTP 管理远端文件
系统 SHALL 在终端下方提供文件面板，复用已认证 SSH 的 SFTP 通道列出目录、名称、类型、大小、修改时间和权限，并支持切换目录、刷新、复制路径、文本查看编辑、上传、下载、创建文件或目录、重命名、删除及权限变更。文件路径 MUST 作为协议数据传输，不得拼接成 Shell 命令。

#### Scenario: 浏览和传输文件
- **GIVEN** 当前 SSH 会话处于连接状态
- **WHEN** 用户在文件面板浏览目录或选择上传、下载
- **THEN** 系统在当前会话身份下执行 SFTP 操作并显示结果或明确错误
- **AND** 会话切换或断开后，旧请求不能覆盖新会话界面

#### Scenario: 确认生产文件变更
- **GIVEN** 当前连接为生产环境
- **WHEN** 用户请求覆盖、删除、重命名、创建或变更权限
- **THEN** 核心先返回操作和路径摘要并等待本次确认
- **AND** 取消时远端保持不变，确认仅对同一会话和操作生效一次

#### Scenario: 处理传输边界
- **WHEN** 文件超过支持的限制、传输中断或结果无法确认
- **THEN** 系统返回明确状态，不声称成功，也不自动重发写入


### Requirement: 在终端下方显示服务器文件夹面板

系统 SHALL 在连接工作台中央区域下方提供服务器文件夹面板，显示当前 SFTP 目录路径、文件夹和文件列表，并提供刷新、路径导航及文件操作上下文菜单。该面板 SHALL 共享当前连接身份，但不得绕过生产文件变更确认。

#### Scenario: 终端与文件夹面板共享连接

- **GIVEN** 用户在连接工作台中选中一个已认证 SSH 连接
- **WHEN** 用户在终端执行命令或在下方文件夹面板浏览目录
- **THEN** 两个面板均使用当前连接身份
- **AND** 切换连接后旧连接的文件请求不能覆盖新连接的文件列表

#### Scenario: 文件面板收起和恢复

- **GIVEN** 用户正在查看远端目录
- **WHEN** 用户收起文件夹面板后再次展开
- **THEN** 系统恢复最近一次可验证的目录和列表状态
- **AND** 未完成的上传、下载或写操作显示明确状态，不因收起面板而伪造成功
