# CoShell 桌面版发行说明

- 顶栏“设置 → 外观”支持“白色”“黑暗”和“跟随系统”。切换时已打开的终端保留会话和历史输出。
- “设置 → 软件更新”显示当前版本。你可以检查、下载正式更新，并在结束 SSH 会话、文件操作和 WebDAV 作业后选择“安装并重启”。
- 使用 0.1.0 或更早版本、或尚未启用在线升级的 0.1.1 本地验收包时，请在本次 Release 下载对应的安装包，手动安装一次以接入后续在线升级。Windows x64 使用 x64 安装程序。macOS 在“关于本机”确认芯片类型，Intel 下载 x64 的 DMG，Apple 芯片下载 aarch64 的 DMG。macOS 安装时把 CoShell 拖到“应用程序”目录并替换同名应用。
- 安装中断后，请从原入口重新打开 CoShell，在“软件更新”查看实际运行版本。若应用无法启动或更新未完成，请从同一正式 Release 下载对应平台的安装包重新安装，并保留已有应用数据目录。
