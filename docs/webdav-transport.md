# WebDAV 传输边界

截至 2026-11-16，桌面版已接入独立目录备份、快照卡片、恢复预览和结果核实。新快照以目录内的清单与完成标记为依据；旧索引协议保留只读兼容。真实服务的验证结果见[独立目录备份验收记录](verification/independent-backup-2026-11-16.md)。

## 内容与保护方式

填写备份口令时，连接包和凭据包在上传前认证加密，包内绑定快照身份、包角色和公开元数据。口令留空时按用户选择明文备份连接信息及全部已保存连接凭据，可跨设备恢复；SHA-256 仅检测损坏，不证明来源。WebDAV 自身凭据、命令历史和终端输出不进入备份。服务器可看到路径、快照/操作标识、摘要、大小和请求时间；标识符不得包含秘密。备份口令遗失后无法恢复加密内容。

本地 `DirectoryOutbox` 始终使用系统凭据存储中的密钥加密，并以附加认证数据绑定操作、规范化目标、账号及目录。密钥缺失时拒绝继续，不重新生成密钥覆盖旧任务，也不降级为明文持久化。

## 独立目录发布

配置目录缺失时通过 `MKCOL` 逐层创建；已存在路径必须通过 DAV collection 响应验证。每次备份使用 UTC 时间 `yyyyMMddHHmmss` 命名子目录，在中国时区查看目录名与本地时间会相差 8 小时。客户端不认领同名未知目录。

```text
20261116120432/manifest.json
20261116120432/connections.pkg
20261116120432/credentials.pkg  # 仅在实际包含已保存凭据时存在
20261116120432/complete.json   # 最后写入，绑定清单摘要与快照 ID
```

发布前先在本地持久化快照归属，上传数据包及清单并读回核对，最后写入完成标记，再核对完整产物。新协议不写入 `latest` 或 `history-*`。目录存在或完成标记存在，均不能单独证明数据通过完整校验。

## 发现与快照卡片

桌面列表契约为 `webdav_list_snapshots(cursor?) → { snapshots, nextCursor, scannedCount }`，每页最多 50 项。使用 Depth 1 枚举备份集合，集合响应上限为 1 MiB、最多 1000 条响应；超限明确报错，不静默截断。条目检查采用有界并发和单条超时，损坏或慢条目不会隐藏正常条目；集合发现失败则整页报错。游标绑定本次列表结果。

卡片展示名称、应用版本、格式版本、大小、保护方式、是否包含凭据、状态和原因。未知大小或版本不填为零或当前应用版本；根据目录名推算时间时明确显示“目录时间（推算）”。列表读取公开元数据，不下载秘密，也不要求输入口令。

卡片区分结构完整、缺失清单、清单损坏、不支持的格式、未完成、缺失连接包、缺失凭据包、完整性不匹配、暂不可用，以及旧格式和未确认旧目录。只有清单声明包含凭据而实际缺包时才显示缺失凭据。`structurally_complete` 只表示基础结构检查通过，不代表摘要和认证加密校验已通过；异常条目禁用恢复。

## 恢复与结果核实

`webdav_preview_snapshot(passphrase, snapshotId)` 完整下载数据，验证长度、摘要并按需解密，返回不含秘密的预览。恢复前明确展示来源、连接字段变更、凭据覆盖、组层级和生产环境策略。浏览、预览及取消不修改本地数据或同步基准，不自动导入主机信任。

预览令牌固定已验证内容、来源目标与账号及本地预期状态。应用恢复时要求没有活动或连接中的会话，使用比较并交换检查本地变更，并通过批次系统凭据日志处理秘密写入。新独立快照不依赖或推进旧 ETag 同步基准；旧格式仅在成功恢复后记录对应基准。

状态为 `running` 或 `unknown` 的上传不直接重发。`webdav_reconcile(operationId)` 对持久记录中的产物执行精确、只读核对，目标或账号变化时拒绝核实。全部匹配后记录成功；核实不会删除远端对象或自动重传，已成功操作重复核实不产生远端写入。

## 旧协议只读兼容

旧时间目录内的 `attempt-*` 是实际负载；`latest` 是已发布入口，`history-<SHA256>` 是前驱索引，`receipt-*` 和 `probe-*` 是旧回执或能力探测对象。仅当旧已发布索引和实际负载均存在时，才作为旧格式备份提供恢复；孤立的旧 `attempt-*` 目录标记为 `legacy_unconfirmed` 并禁用恢复。损坏旧条目不会阻止新独立快照显示。

旧接口 `webdav_list_versions(cursor?) → { versions, nextCursor }` 保留兼容；此前桌面入口返回普通数组而前端期待分页对象的契约缺陷已修复。旧 v2 索引不能由只支持 v1 的旧客户端读取。

新实现不自动迁移、改写或删除旧对象。旧操作的 `cleanup_pending` 和可能对象列表只表示待核查，不构成删除许可；旧结果不明任务也不会自动解锁。
