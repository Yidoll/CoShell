# Spec Delta

## Purpose

定义远程服务器系统概览的指标范围、刷新行为、时间标记和降级展示，使用户能够在不干扰终端会话的前提下快速判断服务器运行与资源状态。

## ADDED Requirements

### Requirement: 展示服务器基础状态
系统 SHALL 展示当前连接的在线状态、主机名、操作系统、内核、体系结构、启动时间和运行时长，并标记数据采集时间。

#### Scenario: 成功加载基础状态
- **GIVEN** 连接在线且远程系统支持基础信息采集
- **WHEN** 用户打开服务器概览
- **THEN** 系统展示服务器身份、运行时长和带时区的采集时间

#### Scenario: 服务器离线
- **GIVEN** 当前连接不可达
- **WHEN** 用户打开或刷新服务器概览
- **THEN** 系统显示离线状态和最近一次成功采集时间
- **AND** 旧数据被明确标识为非实时数据

### Requirement: 展示资源和负载指标
系统 SHALL 展示 CPU 使用率、逻辑核心数、内存总量与用量、系统负载、磁盘容量与用量，以及交换空间总量与用量；数值必须带单位和采集时间。

#### Scenario: Linux 服务器返回完整指标
- **WHEN** 系统成功采集全部支持的服务器指标
- **THEN** 概览分别展示 CPU、内存、负载、磁盘和交换空间的当前值与占比

#### Scenario: 指标在目标系统上不可用
- **GIVEN** 目标系统不提供某项指标或当前用户无读取权限
- **WHEN** 系统生成概览
- **THEN** 对应指标显示“不可用”及非敏感原因
- **AND** 系统不得以数值 0 冒充缺失指标

### Requirement: 支持手动和自动刷新
系统 SHALL 提供手动刷新和可配置的自动刷新；同一连接同一时刻最多执行一次指标采集，新的刷新请求不得造成无界并发。

#### Scenario: 手动刷新成功
- **WHEN** 用户点击刷新且当前没有采集任务
- **THEN** 系统启动一次新采集并在完成后原子替换整组指标和采集时间

#### Scenario: 自动刷新期间切换连接
- **GIVEN** 原连接的指标采集仍在进行
- **WHEN** 用户切换到另一个连接
- **THEN** 系统取消或忽略原连接的过期结果
- **AND** 原连接结果不得覆盖新连接的概览

### Requirement: 指标采集不得干扰终端
系统 MUST 使用独立且有超时的只读采集操作获取系统信息，不得向活动终端注入命令、改变其工作目录或消耗其交互通道。

#### Scenario: 指标采集超时
- **GIVEN** 活动终端仍能正常交互
- **WHEN** 独立指标采集超过超时限制
- **THEN** 系统仅将概览标记为刷新失败
- **AND** 活动终端会话保持可用且输入输出不受影响

### Requirement: 对敏感系统信息进行最小化展示
系统 SHALL 只展示系统概览所需信息，不得在指标响应或日志中包含环境变量、进程命令行、凭据、私钥路径或其他未请求的敏感数据。

#### Scenario: 导出诊断信息
- **WHEN** 用户复制服务器概览诊断信息
- **THEN** 导出内容仅包含已展示指标、稳定错误码和采集时间
- **AND** 内容不包含连接秘密或远程环境变量

### Requirement: 在连接侧栏保留服务器信息入口

系统 SHALL 在左侧连接管理区域提供可展开的“服务器信息”入口，保留当前连接身份、状态和指标刷新能力，不恢复独立系统概览主菜单。

#### Scenario: 展开当前连接的服务器信息

- **GIVEN** 当前工作台已建立 SSH 会话
- **WHEN** 用户展开左侧“服务器信息”
- **THEN** 系统展示当前连接的身份、环境及可用指标
- **AND** 指标获取失败不关闭终端或修改终端输入
