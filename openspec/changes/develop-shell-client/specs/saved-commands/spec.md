# Spec Delta

## ADDED Requirements

### Requirement: 创建和执行保存命令
系统 SHALL 提供命令列表及编辑器，允许用户创建、编辑和删除具名称和内容的命令，持久保存并在重启后读取。用户双击命令时 SHALL 在当前会话执行，并遵循该连接的风险准入和确认策略。

#### Scenario: 双击执行命令
- **GIVEN** 用户已保存命令且当前会话已连接
- **WHEN** 用户双击命令
- **THEN** 系统提交保存的完整内容到当前会话核心准入
- **AND** 生产或始终确认策略不能经命令列表绕过

#### Scenario: 会话不可用
- **WHEN** 用户在未连接、已断开或操作结果未知时请求执行命令
- **THEN** 系统阻止发送并提示建立可用会话

### Requirement: 在连接工作台右侧提供命令管理

系统 SHALL 在连接工作台右侧提供保存命令列表、搜索、分类和双击执行入口，并允许用户收起、展开和调整侧栏宽度。顶部“新建命令”操作 SHALL 展开当前会话的右侧编辑器并聚焦名称；顶部操作和侧栏使用同一实例，不挂载独立命令管理页面。

#### Scenario: 从顶部菜单新建命令

- **GIVEN** 用户正在查看右侧命令管理
- **WHEN** 用户选择“新建命令”
- **THEN** 系统打开命令编辑流程并在保存后将命令加入命令管理列表
- **AND** 保存命令内容不会自动发送到远程会话

#### Scenario: 从右侧命令管理双击执行

- **GIVEN** 用户在连接工作台右侧选中保存命令且当前会话可用
- **WHEN** 用户双击该命令
- **THEN** 系统将完整命令提交当前会话的风险准入流程
- **AND** 右侧面板收起、展开或切换配置区域不能绕过生产连接确认


### Requirement: 未连接时仍可维护保存命令

系统 SHALL 在没有可用 SSH 会话时保留命令管理侧栏并允许创建、编辑和保存命令；运行操作 MUST 被阻止，直到当前会话可用且通过既有风险准入。

#### Scenario: 未连接时创建命令

- **GIVEN** 当前工作台尚未建立 SSH 会话
- **WHEN** 用户选择顶部“新建命令”并保存名称和内容
- **THEN** 命令通过既有本地持久化流程保存
- **AND** 运行操作不可用，不创建 SSH 连接或自动发送命令
