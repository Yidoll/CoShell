# 桌面在线升级

## Purpose

让 Windows 和 macOS 用户在 CoShell 内检查并获取适合当前设备的正式版本，在结束远程工作后安装新版。发布者提供可验证的更新包，使下载异常或安装推迟时用户仍可使用当前版本。

## ADDED Requirements

### Requirement: 手动检查适用的正式版本
桌面设置 SHALL 展示当前运行版本，并允许用户手动检查正式发布源。只有适配当前平台和架构且版本高于当前版本的稳定版才可供下载。Web 入口 SHALL 明确说明桌面升级仅适用于桌面版。

#### Scenario: 发现新版本
- **WHEN** 用户检查更新，发布源提供适用的更高稳定版本
- **THEN** 界面显示当前版本、可用版本、可获得的发行说明和下载入口，由用户决定是否下载

#### Scenario: 最新版本与异常状态
- **WHEN** 正式清单有效且版本等于或低于当前版本
- **THEN** 界面提示已是最新，无安装入口
- **WHEN** 网络超时、清单损坏或缺少适用的更新包
- **THEN** 界面区分检查失败与无适用更新，提供重试，当前应用可继续使用

### Requirement: 下载并验证更新
客户端 MUST 通过 HTTPS 获取更新并使用内置更新公钥验证包的签名。下载期间 SHALL 显示进度，支持取消和重试，同一时刻最多运行一个升级操作。

#### Scenario: 下载中断或取消
- **WHEN** 用户取消下载或网络连接中断
- **THEN** 客户端结束本次下载，丢弃不完整的内容，用户可重新下载
- **AND** 已打开的 SSH 会话与 SFTP 传输继续工作

#### Scenario: 包被替换或签名无效
- **WHEN** 下载内容与清单中的签名不匹配
- **THEN** 客户端报告校验失败，丢弃该包并禁止启动安装程序

### Requirement: 用户确认后安全安装
客户端 SHALL 在下载验证完成后提供“稍后”和“安装并重启”。开始安装前 MUST 复核当前工作状态并取得确认；有活动或连接中的 SSH 会话、进行中的文件操作或 WebDAV 备份还原时应提示用户先处理这些工作。

#### Scenario: 暂缓安装
- **WHEN** 用户选择稍后，或在下载后新开了会话而后点击安装
- **THEN** 客户端保持运行，说明如何返回安装，或列出当前阻止安装的工作类型

#### Scenario: 安装并重新打开
- **WHEN** 用户已结束相关工作并确认安装，安装和重启成功
- **THEN** 设置显示新版的实际运行版本，原有连接资料、凭据引用和主题偏好仍可用

#### Scenario: 安装失败
- **WHEN** 平台安装失败、权限不足或用户取消系统安装提示
- **THEN** 应用仍在运行时显示失败原因及可用操作，若已退出则允许通过原启动入口或官方安装包恢复，以下次实际启动版本判断结果

### Requirement: 发布完整的跨平台更新
正式更新源 SHALL 为 Windows x64、macOS Intel 和 Apple Silicon 提供匹配的包、签名和一致的版本信息，全部文件验证通过后才对稳定版客户端可见。

#### Scenario: 某一目标未完成
- **WHEN** 任何目标缺少包或签名，或标签版本与包内版本不符
- **THEN** 发布流程停止推广该版，已有稳定版清单仍可用

#### Scenario: 旧用户接入升级通道
- **WHEN** 用户从尚未内置升级器的 0.1.1 安装首个支持升级的正式版
- **THEN** 发行说明指导一次手动安装，之后可在设置中检查后续版本
