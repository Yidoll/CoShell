## 格式与发布验证

- 格式测试验证独立 `manifest.json`、`connections.pkg`、可选 `credentials.pkg`、`complete.json`，应用/格式版本分离，口令可选，加密包身份/角色/公开元数据认证绑定，以及固定路径、长度、摘要、包存在性和损坏 framing 拒绝。
- core 真实 SQLite + 模拟系统存储验证私钥/口令目录快照往返，排除历史、终端输出和 WebDAV 自身凭据。
- mock HTTP 验证完整标记最后写入、目录冲突不覆盖、上传中断无完成标记、完成响应丢失后只读核实、完成后 GET 认证失败保留未知、缺清单、坏清单、不支持格式、缺凭据包、大小不符、坏旧索引、旧负载缺失、非法日期、慢条目隔离、旧目录去重及无 `latest` 仍发现新快照。
- `DirectoryOutbox` 真实磁盘/WAL 测试验证无明文包落盘；操作、规范化目标、账号和目录受本地认证加密绑定，错误密钥或归属篡改拒绝读取。重开后的 `running/unknown` 不自动重发，通过 `webdav_reconcile` 核对完整 artifact 后才记录成功。
- DesktopRuntime 的本地 HTTP/SQLite/模拟系统存储集成测试覆盖新同步、卡片真实序列化、完整预览、预览零基准写入、成功操作重试零写入、未知结果只读核实，以及目标变化后恢复/旧操作均拒绝且不创建新目标目录。

## 后续验收边界

- 新快照集合发现受 1 MiB/1000 响应的显式上限约束，每页 50 项；超限报错，不静默声称已列出所有条目。
- 单条元数据检查超时标记暂不可检查；不把权限/网络错误解释为文件缺失。
- 无口令模式不提供保密或来源认证；列表中的“结构完整”不等于内容已经认证通过。
- 旧未知记录不会直接删除或自动重发；旧索引和孤立文件只读保留。
