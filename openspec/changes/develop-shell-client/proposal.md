# Proposal

## Why

CoShell 的初始基线只有验证多入口架构的健康检查骨架。本变更逐步建立面向 Windows 与 macOS 的桌面 Shell 客户端能力，让用户能够管理 SSH 连接、执行命令、查看服务器状态，并可靠备份连接配置；当前实施范围和剩余验收见 `design.md` 与 `tasks.md`。

## What Changes

- 提供 Windows 与 macOS 桌面客户端，并保证两端的核心 Shell 工作流和数据格式一致。
- 新增 SSH 连接管理，支持创建、编辑、测试、分组、删除连接，以及密码和密钥认证；连接可标识为生产环境。
- 新增交互式终端会话，支持连接、断开、重连、标签页、终端尺寸同步、复制粘贴和常用终端快捷操作。
- 新增服务器系统概览，展示在线状态、运行时间、CPU/内存、负载、磁盘和交换空间等信息，并支持手动刷新和定时刷新。
- 新增命令操作历史，记录命令、连接、时间、执行结果和耗时，支持搜索、筛选、再次填入与清理。
- 新增生产环境命令守护：危险命令默认以红色显示；在生产连接上执行危险命令前必须展示风险说明并由用户明确确认。
- 新增 WebDAV 备份配置，用于可选口令保护的连接资料与已保存连接凭据备份，并提供服务器连接检查、冲突处理和失败反馈；WebDAV 自身凭据、终端输出和命令历史不进入备份。
- 根据 2026-11-14 的新增要求，提供复用现有 SSH 身份的 SFTP 文件管理，以及可创建并双击执行的保存命令；文件面板位于终端下方，保存命令通过右侧面板管理。
- WebDAV 备份重设计为独立快照目录和清单驱动的“查看备份”卡片列表，按清单时间倒序展示版本、大小、保护方式、凭据状态和校验状态，用户可选择任意通过检查的版本恢复；移除独立系统概览菜单，保留会话侧栏的服务器指标。
- 根据 2026-11-16 的“查看备份”参考图，重新设计备份为每目录独立的 `manifest.json`、连接数据包、按需凭据包和最终完成标记。列表以卡片展示名称、创建时间、应用版本、格式版本、大小、保护方式、凭据情况及可恢复状态；异常备份保留可见并显示明确原因，只有通过基础检查的条目可进入恢复预览。
- 新格式已以目录内清单和完成标记为权威，不依赖全局 `latest/history-*` 链发现新快照；旧格式提供只读兼容入口，孤立旧对象不自动认定为完成备份，不自动改写或删除旧远端数据。重设计任务 10.1–10.6 已实现并评审，真实服务独立快照验收见 `docs/verification/independent-backup-2026-11-16.md`；该验证不替代 8.x 的平台完整验收。
- 依据 dbx 界面与用户最新标注图调整布局：顶部最左侧只保留“新建连接”“新建命令”“WebDAV 配置”直接操作，移除大品牌区、重复功能标签和页面大标题。左侧固定连接管理，中间上方为终端、下方为 SFTP 文件面板，右侧为贯穿高度的命令管理；未连接时也保留区域。侧栏收起保留目录和草稿，配置切换不卸载会话。
- 布局首轮实现与截图校正已完成，对应第 11、12 节；不复制 dbx 业务依赖，代码变更仅限 CoShell 自有界面壳层、面板状态和样式。
- 不在本变更中提供独立 FTP/FTPS、端口转发、多人协作、云端账号体系、移动端或 Linux 桌面客户端。

## 当前交付状态

截至 2026-11-17，本变更完成 38/70 项任务，剩余 32 项按原验收要求继续跟踪。第 10 节备份重设计及第 11、12 节布局实现已完成；Windows x64 安装包已生成，macOS 安装包、真实平台安装及系统辅助技术验收尚未完成。本次仅同步文档，不新增功能、不归档变更。验证记录与产物索引见 `verification.md`。

## Capabilities

### New Capabilities

- `desktop-platform-support`: 约束 Windows 与 macOS 的安装、启动、核心功能一致性和平台凭据存储行为。
- `remote-connections`: 管理 SSH 连接资料、认证方式、分组、连接测试和生产环境标识。
- `terminal-sessions`: 建立并管理交互式 SSH Shell 会话、终端输入输出和会话生命周期。
- `server-overview`: 采集并展示远程服务器运行状态、负载、资源和交换空间信息。
- `command-history`: 持久化、查询、复用和清理命令操作历史，同时保护敏感内容。
- `production-command-guard`: 识别危险命令、红色高亮，并在生产连接执行前强制确认。
- `webdav-connection-backup`: 配置 WebDAV，浏览独立备份目录及其清单状态，对连接资料执行可选加密、完整性验证、预览恢复和冲突处理。
- `remote-file-management`: 通过现有 SSH 会话管理、编辑和传输远端文件，并确认生产变更。
- `saved-commands`: 持久化用户创建的命令，并通过当前会话统一准入执行。
- `desktop-workspace-layout`: 约束参考 dbx 的视觉基线、三项左对齐的顶部操作、连接工作台面板分区、面板调整和跨平台可用性。

### Modified Capabilities

无。当前 OpenSpec 主规格为空，本变更全部为新增能力。

## Impact

- 前端工作台将从系统概览扩展为连接侧栏、终端工作区、服务器概览、历史记录和设置界面，并继续通过统一 Backend API 访问能力。
- `coshell-types` 将新增连接、会话、系统指标、历史、安全判定、备份和稳定错误码等跨入口契约。
- `coshell-drivers` 将承担 SSH 传输、认证、终端通道和远程系统信息采集；`coshell-platform` 将承担 Windows/macOS 安全凭据和本地路径原语。
- `coshell-core` 将编排连接、会话、历史、生产守护和 WebDAV 备份流程；Tauri Command 与 Axum Route 作为薄适配层共享同一业务实现。
- 需要新增终端渲染、SSH、凭据存储、加密和 WebDAV 客户端依赖，并评估其许可证、跨平台构建与发布影响。
- 连接凭据、私钥、历史命令和备份内容进入安全边界；必须覆盖加密存储、日志脱敏、超时取消、原子写入、恢复校验和失败回滚。
- 功能按本地配置版本号演进，较高版本 schema 不被旧版本破坏性降级；已有远端旧备份通过只读兼容读取，不进行隐式迁移。
- 备份重设计已新增外层目录格式及清单 DTO，覆盖 `coshell-backup` 的发现/校验、`coshell-core` 的备份和恢复编排、统一前端 API 和备份卡片界面。已有备份载荷格式仍由兼容读取器处理，不通过删除或原地改写旧文件完成升级。
- 工作台布局已调整前端壳层、导航状态、终端/文件面板组合、连接列表和保存命令面板；业务访问继续通过统一 Backend API，不改变 Rust 领域契约。dbx 仅作为视觉和交互参考，不复制其数据库功能或业务模型。
