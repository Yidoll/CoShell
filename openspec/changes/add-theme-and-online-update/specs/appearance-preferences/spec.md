# 主题偏好

## Purpose

用户可以在不同光照环境下选择合适的外观，也可以让界面随操作系统自动切换。工作台、弹窗和已打开的终端应采用一致的配色，并保留正在进行的操作。

## ADDED Requirements

### Requirement: 选择并记住主题
共享界面 SHALL 在设置中提供“白色”“黑暗”“跟随系统”三个互斥选项，默认选中“跟随系统”。用户选择后 SHALL 立即生效，并在同一客户端下次启动时恢复。

#### Scenario: 固定黑暗或白色
- **WHEN** 用户选择黑暗或白色，然后更改系统外观并重启应用
- **THEN** 启动界面和工作台均使用用户选定的主题，设置展示对应选项

#### Scenario: 存储异常
- **WHEN** 保存值缺失、无效或本地偏好存储不可读
- **THEN** 本次按跟随系统启动，系统外观也无法识别时采用白色
- **AND** 若写入偏好失败，本次切换仍生效，界面提示选择仅对本次有效

### Requirement: 运行中更新所有界面的可读配色
桌面与 Web 入口 SHALL 使用相同的主题选择规则。跟随系统时，系统外观变化 SHALL 更新启动页、工作台、设置和终端。切换 MUST 保留会话内容和操作状态，生产环境危险命令在两种配色下均须保留清晰可辨的红色及已有文字提示。

#### Scenario: 跨会话切换系统外观
- **GIVEN** 用户选择跟随系统，同时打开多个 SSH 标签并在其中一个终端滚动查看历史输出
- **WHEN** 系统由白色切换为黑暗，再切回白色
- **THEN** 所有标签采用对应的终端背景、前景、选区和光标颜色，当前标签、历史内容及滚动位置保留
- **AND** 文件面板、连接列表、命令面板、WebDAV 表单及右键菜单的文字、焦点和选中态仍清晰可辨

#### Scenario: 切换时有待确认的危险命令
- **WHEN** 生产连接的危险命令仍在等待确认，系统主题发生变化
- **THEN** 既有红色文字和确认提示仍可读，命令保持待确认状态，主题切换不发送命令
