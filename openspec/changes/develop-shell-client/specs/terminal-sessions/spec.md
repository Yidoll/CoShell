# Spec Delta

## Purpose

定义交互式 SSH Shell 会话从创建到关闭的可观察行为，包括终端输入输出、标签页管理、窗口尺寸同步、断线处理和资源释放，使日常远程命令操作稳定可控。

## ADDED Requirements

### Requirement: 建立交互式 SSH 终端
系统 SHALL 基于已保存或临时 SSH 连接创建带伪终端的交互式 Shell 会话，并以流式方式显示远程输出和提交用户输入。

#### Scenario: 成功打开终端
- **GIVEN** 连接配置和认证有效且主机身份已受信任
- **WHEN** 用户选择打开终端
- **THEN** 系统创建终端标签页并显示远程 Shell 提示符
- **AND** 用户输入能够按顺序送达当前会话

#### Scenario: 会话建立失败
- **WHEN** SSH 或伪终端创建失败
- **THEN** 系统将标签页置为失败状态并显示稳定错误码与可重试操作
- **AND** 系统释放已创建的网络和认证资源

### Requirement: 管理多个终端标签页
系统 SHALL 允许用户同时打开多个终端标签页，清晰展示连接名称、生产环境标识和连接状态，并保持每个标签页的输入输出隔离。

#### Scenario: 在两个连接间切换
- **GIVEN** 用户已打开两个连接的终端标签页
- **WHEN** 用户切换活动标签页
- **THEN** 系统显示目标会话的独立终端缓冲区和状态
- **AND** 输入只发送到当前活动会话

#### Scenario: 关闭活动会话
- **GIVEN** 终端会话仍处于连接状态
- **WHEN** 用户关闭标签页并确认断开
- **THEN** 系统关闭远程通道、停止后台读取并释放会话资源

#### Scenario: 通过标签菜单管理会话
- **GIVEN** 工作区包含一个或多个会话标签
- **WHEN** 用户打开标签的上下文菜单
- **THEN** 系统提供复制标签、断开、关闭、关闭其他和关闭全部操作
- **AND** 复制标签建立独立会话，不复制临时认证秘密
- **AND** 批量关闭前要求确认活动会话，关闭结果未知时保留对应标签供用户处理

### Requirement: 同步终端尺寸和常用交互
系统 SHALL 将可见终端的行列尺寸变化同步到远程伪终端，并支持文本选择、复制、粘贴、清屏和键盘导航等常用终端操作。

#### Scenario: 调整窗口尺寸
- **GIVEN** 终端会话处于连接状态
- **WHEN** 用户调整终端区域大小
- **THEN** 系统向远程伪终端发送最新行列尺寸且不重建会话

#### Scenario: 粘贴多行文本
- **GIVEN** 剪贴板包含多行文本
- **WHEN** 用户向终端执行粘贴
- **THEN** 系统在发送前展示多行粘贴确认和内容摘要
- **AND** 用户取消时不向远程会话发送任何粘贴内容

### Requirement: 明确处理断线与重连
系统 SHALL 检测远程关闭、网络中断和超时，保留只读终端输出并允许用户发起新会话重连；重连不得自动重放未确认命令。

#### Scenario: 网络连接中断
- **GIVEN** 会话正在运行
- **WHEN** 底层 SSH 连接意外断开
- **THEN** 系统停止接受该会话的新输入并显示断线时间和原因
- **AND** 已显示的终端输出仍可查看和复制

#### Scenario: 用户发起重连
- **GIVEN** 原会话已断开
- **WHEN** 用户选择重连且认证成功
- **THEN** 系统创建新的会话实例并保留原会话输出供查阅
- **AND** 系统不自动发送原会话中未完成或未确认的输入

### Requirement: 支持取消和有界资源使用
系统 MUST 为会话创建、读取和关闭操作提供超时与取消语义，并限制单会话终端回滚缓冲区，避免失联会话或无限输出持续占用资源。

#### Scenario: 终端持续产生大量输出
- **WHEN** 会话输出超过配置的回滚缓冲上限
- **THEN** 系统丢弃最旧的可视历史并保持最新输出可用
- **AND** 系统不得因无限增长的缓冲区耗尽客户端内存

#### Scenario: 应用退出
- **GIVEN** 存在一个或多个活动会话
- **WHEN** 用户退出应用
- **THEN** 系统取消后台任务并在有界时间内关闭所有 SSH 通道和连接

### Requirement: 跨传输保持会话事件一致
系统 SHALL 为 Tauri 与 HTTP 入口使用相同的会话状态和错误契约；流式输出、断线和关闭事件必须携带会话标识及单调递增序号。

#### Scenario: 客户端收到重复会话事件
- **GIVEN** 客户端已处理某个会话序号
- **WHEN** 传输层再次交付相同或更早序号的事件
- **THEN** 客户端忽略重复事件且终端内容不重复追加

### Requirement: 在连接工作台中央上方显示终端

系统 SHALL 在连接工作台中央区域上方显示当前会话的终端，并在终端工具条中展示连接名称、生产环境标识、会话状态和标签上下文菜单。终端区域 SHALL 与下方服务器文件夹面板通过可调整分隔线划分，且在窗口缩放和侧栏调整后保持输入可见。

#### Scenario: 调整终端与文件面板比例

- **GIVEN** 当前连接已打开终端和服务器文件夹面板
- **WHEN** 用户拖动中央区域的水平分隔线
- **THEN** 终端与文件面板按新比例重新布局
- **AND** 终端最低输入区域不会被文件面板遮挡或裁切

#### Scenario: 切换顶部操作后返回连接工作台

- **GIVEN** 终端正在持续接收输出
- **WHEN** 用户查看 WebDAV 配置后返回会话
- **THEN** 原终端标签、输出缓冲区、连接上下文和生产提示仍可见
- **AND** 配置切换不向远程会话注入输入
