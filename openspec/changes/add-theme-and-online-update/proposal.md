# 桌面主题与在线升级

## Why

工作台能随系统改变部分颜色，但用户无法固定主题，终端也有独立的固定配色。桌面用户要获取新版，目前需要自行寻找安装包，且正在使用 SSH 或传输文件时需要自己判断何时退出。

## What Changes

- 在现有顶栏右侧增加设置入口，提供白色、黑暗、跟随系统三种模式。偏好保存在本机，应用到启动页、工作台和终端。
- 桌面用户可在设置中手动检查稳定版，查看版本和发行说明，下载后选择安装时机。升级程序核验签名，应用在会话和文件操作结束后交接安装。
- 正式发布时生成 Windows x64、macOS Intel 和 Apple Silicon 更新包，统一通过 GitHub Releases 分发。已有 0.1.1 用户首次手动安装带升级器的版本。

## Capabilities

### New Capabilities

- `appearance-preferences` 定义主题选择、持久化及运行中切换的行为。
- `desktop-online-update` 定义检查、下载、安装与发布端契约。

### Modified Capabilities

当前主规格目录为空。已有活动变更中关于工作台布局、生产危险命令和会话生命周期的约束继续适用。

## Impact

影响共用 Vue 界面、Tauri 桌面入口、构建版本来源及正式发布工作流。Web 入口支持主题，安装能力限于桌面。此提案的发布范围为稳定版、用户主动检查和用户确认安装。
