# Spec Delta

## Purpose

定义命令操作历史的记录范围、检索复用、敏感信息保护和生命周期控制，使用户可以审计与重复日常操作，同时避免历史成为新的秘密泄露来源。

## ADDED Requirements

### Requirement: 记录已提交的命令操作
系统 SHALL 在用户向远程 Shell 提交命令时记录连接标识、连接名称快照、生产标识快照、命令文本或脱敏摘要、提交时间、完成状态、退出码和可获得的执行耗时。

#### Scenario: 命令正常完成
- **GIVEN** 用户已提交非敏感命令
- **WHEN** 系统获知该命令完成及退出码
- **THEN** 历史记录包含命令文本、连接上下文、开始时间、耗时和退出码

#### Scenario: 会话在结果返回前断开
- **GIVEN** 命令已经提交
- **WHEN** 会话在无法确认退出码时断开
- **THEN** 历史记录标记结果为未知且保留已知的提交时间和连接上下文

### Requirement: 检索和筛选命令历史
系统 SHALL 支持按关键词、连接、生产标识、时间范围和执行结果检索历史，并以分页或虚拟化方式有界加载结果。

#### Scenario: 筛选失败命令
- **WHEN** 用户选择某连接并筛选非零退出码
- **THEN** 系统只返回该连接在指定范围内已知失败的命令记录

#### Scenario: 历史数量较大
- **GIVEN** 本地存在超过单页限制的历史记录
- **WHEN** 用户打开历史页面
- **THEN** 系统仅加载首批结果并允许继续加载
- **AND** 界面不会一次性将全部记录装入内存

### Requirement: 安全复用历史命令
系统 SHALL 允许用户将历史命令重新填入当前终端的命令输入区，但 MUST NOT 因选择、双击或恢复历史而自动执行命令。

#### Scenario: 从历史填入命令
- **GIVEN** 用户选择一条普通历史命令
- **WHEN** 用户执行“填入终端”操作
- **THEN** 命令进入当前会话的输入区并等待用户提交

#### Scenario: 复用危险历史命令
- **GIVEN** 历史命令被判定为危险
- **WHEN** 用户将其填入终端
- **THEN** 输入内容保持危险命令红色高亮
- **AND** 在生产连接提交时仍执行当前生产守护流程

### Requirement: 保护历史中的敏感内容
系统 MUST 在持久化前识别密码输入、Token、私钥内容和常见秘密赋值；能够确定为秘密的内容不得保存原文，不确定但疑似敏感的命令必须脱敏或允许用户禁用该连接的历史记录。

#### Scenario: 交互式密码提示输入
- **GIVEN** 终端处于密码或口令输入提示
- **WHEN** 用户提交输入
- **THEN** 系统不创建包含该输入内容的历史记录

#### Scenario: 命令包含常见 Token 参数
- **WHEN** 用户提交包含受识别 Token 或密码参数的命令
- **THEN** 历史仅保存脱敏后的命令或安全摘要
- **AND** 日志、搜索索引和错误信息均不包含秘密原文

### Requirement: 管理历史保留和清理
系统 SHALL 允许用户配置本地历史保留天数或最大条数，并支持清除全部历史或指定连接、时间范围的历史；清理操作必须在执行前展示影响范围。

#### Scenario: 清除指定连接历史
- **GIVEN** 用户确认清除某连接的全部历史
- **WHEN** 清理完成
- **THEN** 该连接的历史和搜索索引均被删除
- **AND** 其他连接的历史保持不变

#### Scenario: 自动执行保留策略
- **WHEN** 历史超过用户配置的保留期限或最大条数
- **THEN** 系统优先删除最旧记录并保持数据库处于一致状态

### Requirement: 历史默认仅保存在本地
系统 SHALL 将命令历史保存在本地应用数据中，默认不得把命令历史包含在 WebDAV 连接备份或其他同步内容中。

#### Scenario: 创建 WebDAV 连接备份
- **GIVEN** 本地存在命令历史
- **WHEN** 用户执行连接信息备份
- **THEN** 备份清单不包含命令文本、命令摘要或执行结果
